# 知天易 · tianyi-astro

一个以 **科学依据驱动的 3D 天文可视化 + 数字化数据解读** 为核心的科普网站：用 3D 场景看现象，用真实数据理解尺度。

> 所有 3D 贴图均为**程序化生成**（Canvas + 噪声算法），不依赖外部图片资源，离线可用；场景尽量基于真实物理参数，而非大众印象；数据条目统一标注单位与近似程度。

## 🧭 四个核心能力

### 1. 数字化视角：把数量级变成看得懂的对比

每个展项的「数据」标签页由自研可视化组件构成（纯 DOM/SVG，零第三方依赖）：

- **对数尺度对比条**：把 8.9 毫米（地球史瓦西半径）到 1.2×10¹¹ 千米（M87\* 史瓦西半径）放进同一条对数轴，悬停/聚焦显示真实数值与倍率
- **数值仪表网格**：直径 / 质量 / 表面重力 / 平均温度 / 公转与自转周期 / 密度 / 逃逸速度，带「地球」参照刻度
- **对比矩阵**：与参照天体逐项对比，直接给出「11.2×」这类倍率
- **SVG 条形图**：支持对数刻度与容器自适应重绘

数据覆盖全部 24 个展项，来源为 NASA Planetary Fact Sheet、IAU 名义值、EHT / Gaia / Hubble 公开结果等公认常数；温度统一用开尔文、近似值标 ≈。

### 2. 3D 科学可视化

- 🌞 **太阳**：光球米粒组织、太阳黑子、临边昏暗效应
- 🪐 **行星**：真实自转方向与轴倾角（金星逆行、天王星 98° 侧躺）、金星浓厚硫酸云、木星大红斑、火星暗色区域、海王星暗斑、冥王星亮暗区域
- 🪐 **土星环**：程序化卡西尼缝
- 🕳️ **黑洞**：引力透镜光路追踪，阴影半径 ≈ 2.6 Rs、光子环贴住阴影边缘、吸积盘内缘 ISCO ≈ 3 Rs、多普勒束流
- ☄️ **哈雷彗星**：离子尾笔直背向太阳，尘埃尾沿轨道向后弯曲
- 🌌 **银河系**：棒旋结构、老年黄色核心与年轻蓝色旋臂
- 🌠 **流星雨**：轨迹交汇于辐射点
- 🟢 **极光**：颜色按海拔分层——低层蓝紫（氮）、中层绿（氧）、高层红（氧）
- 🌑 **日食**：月球本影锥与全食时日冕
- 💥 **超新星**：核坍缩抛射物与中心中子星遗迹
- 🪐 **太阳系总览**：轨道半径对数压缩，公转相对速度基于真实周期（开普勒第三定律）

### 3. 交互与体验

- ⏱️ **时间控制**：公转/自转倍率 0.1×–32× 九档 + 暂停/播放
- 🎥 **视角预设**：近观 / 轨道 / 俯视 / 侧视，平滑过渡，拖拽可随时接管
- 🎯 **点击拾取**：命中天体或特征（吸积盘、光子环、大红斑、彗尾…）弹出 HUD 信息卡
- 📸 **保存快照**、自动旋转、重置视角
- ⌨️ **键盘**：←/→ 上下展项、1–4 切标签、空格暂停、R 重置、Esc 关闭；输入框聚焦时不劫持
- 🔗 **深链**：`#/p/blackhole?tab=facts` 刷新后停留在同一标签
- 🔍 **全局搜索**：Ctrl/⌘+K 聚焦、↑↓ 选择、Enter 打开、分类过滤、关键词高亮
- 🕘 **最近查看**：自动记录浏览足迹（localStorage，最多 6 条）
- 📱 **移动端**：≤900px 自动切为底部三档吸附抽屉，触摸目标 ≥44px，375px 无横向滚动

### 4. 真实感渲染管线

- **ACES 影调映射 + sRGB 输出**：恒星、吸积盘、冰面的高光被压回可视范围，不再硬截断成死白
- **程序化 IBL 环境光照**：深空渐变 + 定向亮星经 `PMREMGenerator` 预卷积成辐照度贴图，低粗糙度表面获得方向性环境反射（零外部贴图依赖）
- **法线贴图**：与反照率同源的 fbm 高度场（含环形山碗状剖面）生成表面起伏，岩石行星与卫星在斜射光下出现真实凹凸
- **地球海面反光**：粗糙度贴图让海洋出现太阳镜面反射，陆地保持漫反射
- **按场景测光**：亮表面天体（月球）与高密度粒子场景（星系、星云）各自使用合适的曝光
- **真实星空**：按光谱型抽样恒星颜色（B/A/F/G/K/M 黑体色）、按星等幂律分布亮度，约三成恒星聚集在银河带

### 5. 科幻 HUD 视觉系统

- 全局细网格 + 四边刻度尺 + 扫描带 + 数据流粒子（Canvas 2D，性能预算 ≤3ms/帧，超预算自动降质）
- 等宽数字（`tabular-nums`）、发光基准线、面板四角标、hover 扫描扫过、焦点高亮环
- 复古未来（衬线标题 + 米色正文）为底，HUD 仪器层叠加其上；全部动效支持 `prefers-reduced-motion`

## ⚡ 加载性能

第三轮迭代把「首屏」和「三维引擎」彻底分开：首页、目录页、天文史页的关键路径**完全不含 three.js**。

| 指标 | 优化前 | 优化后 |
| --- | --- | --- |
| 首页 FCP | 568 ms | **52 ms** |
| 首页关键 JS 传输量 | 215 KB | **36 KB** |
| 详情页 FCP（文字先出） | 228 ms | **48–68 ms** |
| 太阳系场景构建 | 279 ms | **113 ms** |
| 入口 chunk | 766 KB（含 three） | **52 KB**（three 独立成 562 KB 按需块） |

做法：

1. `index.html` 内联启动骨架与关键样式，冷启动立即有画面；路由渲染推迟两帧保证骨架真的上屏
2. 路由级动态 `import()`：详情 / 目录 / 时间线按需加载；详情路由并行预取 `viewer` + `scenes`
3. 详情页两段式：外壳、文字、数据表先渲染，三维引擎到达后再构建场景（加载态分「加载引擎 → 构建场景」两段）
4. `metrics` 与 `viz` 只在打开「数据」页时下载；切标签会取消未完成的异步渲染
5. HUD 背景层在首帧后空闲期加载并淡入；页面隐藏时自动暂停
6. 悬停/聚焦展项卡片时预取三维引擎，点击进详情基本是「已就绪」观感
7. 纹理生成：颜色运算就地写入（消除每像素数组分配）、噪声查表、概览场景降分辨率
8. 构建时 `three` 独立成 vendor chunk 长期缓存

## 🚀 快速开始

```bash
npm install       # 安装依赖
npm run dev       # 本地开发，默认 http://localhost:5173
npm run build     # 类型检查 + 生产构建（输出到 dist/）
npm run preview   # 预览生产构建
```

## ♿ 无障碍与性能

- 全部交互元素可键盘到达，`:focus-visible` 高亮环；图表带 `role`/`aria-label` 纯文本读数
- 正文对比度 ≥ WCAG AA（实测 6.8–14.3）
- 375px 视口零横向滚动；`prefers-reduced-motion` 下关闭漂移/闪烁/扫描动画
- HUD 背景层按帧耗时预算自适应降质，页面隐藏时暂停渲染
