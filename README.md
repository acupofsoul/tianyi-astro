# 天一天文馆 · tianyi-astro

一个以 **3D 交互可视化**为核心的天文科普网站：搜索并查看太阳系、行星、黑洞、彗星、星云等天文现象的 3D 场景，同时阅读每个天体的文字介绍与科学原理解释。

> 所有 3D 贴图均为**程序化生成**（Canvas + 噪声算法），不依赖任何外部图片资源，离线可用。

## ✨ 功能特性

- 🪐 **3D 太阳系总览**：太阳与八大行星绕日公转，带轨道线、自转与土星环
- 🌍 **行星 3D 模型**：水星 → 海王星 + 冥王星，各自带自转、轴倾角、大气辉光、云层
- 🕳️ **黑洞场景**：事件视界 + 光子环 + 带多普勒效应的吸积盘着色器
- ☄️ **哈雷彗星**：冰核 + 彗发 + 尘埃尾与离子尾粒子系统
- 🌫️ **星云 / 银河系**：数千粒子组成的彩色星云与螺旋星系
- 🌠 **流星雨 / 极光 / 日食 / 超新星**：动态粒子与着色器动画
- 🔍 **检索 + 分类筛选**：按名称/标签搜索，按类别（行星/恒星/深空天体/天文现象…）筛选
- 📖 **科普内容**：每个天体都有简介、科学原理、数据档案
- 🖱️ 3D 场景支持**拖拽旋转、滚轮缩放**

## 🛠️ 技术栈

- [Vite](https://vite.dev) + TypeScript（零框架，轻量）
- [Three.js](https://threejs.org) + OrbitControls
- 程序化纹理：Value Noise / FBM、Canvas 2D

## 🚀 快速开始

```bash
npm install       # 安装依赖
npm run dev       # 本地开发，默认 http://localhost:5173
npm run build     # 类型检查 + 生产构建（输出到 dist/）
npm run preview   # 预览生产构建
```

## 📂 目录结构

```
src/
├── main.ts            # 入口
├── style.css          # 全局样式
├── types.ts           # 类型定义
├── catalog.ts         # 天文现象数据（20 个条目：介绍/科学原理/数据）
├── textures.ts        # 程序化纹理生成器
├── scenes.ts          # 12 类 3D 场景构建器
├── viewer.ts          # WebGL 渲染器 + 轨道控制封装
└── ui/
    ├── router.ts      # hash 路由
    ├── home.ts        # 首页（英雄区星空 + 检索 + 卡片）
    └── detail.ts      # 详情页（3D 查看器 + 科普文本）
```
