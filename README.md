# 知天易 · tianyi-astro

一个以 **科学依据驱动的 3D 天文可视化**为核心的科普网站：搜索并查看太阳系、行星、黑洞、彗星、星云等天文现象的 3D 场景，同时阅读每个天体的文字介绍、科学原理与数据档案。

> 所有 3D 贴图均为**程序化生成**（Canvas + 噪声算法），不依赖外部图片资源，离线可用；场景尽量基于真实物理参数，而非大众印象。

## ✨ 科学可视化要点

- 🌞 **太阳**：光球米粒组织、太阳黑子、临边昏暗效应
- 🪐 **行星**：真实自转方向与轴倾角（金星逆行、天王星 98° 侧躺）、金星浓厚硫酸云、木星大红斑、火星暗色区域、海王星暗斑、冥王星亮暗区域
- 🪐 **土星环**：程序化卡西尼缝
- 🕳️ **黑洞**：阴影半径 ≈ 2.6 Rs、光子环、吸积盘内缘 ISCO ≈ 3 Rs、多普勒束流
- ☄️ **哈雷彗星**：离子尾笔直背向太阳，尘埃尾沿轨道向后弯曲
- 🌌 **银河系**：棒旋结构、老年黄色核心与年轻蓝色旋臂
- 🌠 **流星雨**：轨迹交汇于辐射点
- 🟢 **极光**：颜色按海拔分层——低层蓝紫（氮）、中层绿（氧）、高层红（氧）
- 🌑 **日食**：月球本影锥与全食时日冕
- 💥 **超新星**：核坍缩抛射物与中心中子星遗迹
- 🪐 **太阳系总览**：轨道半径对数压缩，公转相对速度基于真实周期（开普勒第三定律）

## ✨ 交互功能

- 🧭 顶部菜单 + 目录页：按顺序浏览 20 个条目，详情页支持上一篇/下一篇
- 🔍 全局搜索（实时建议 + 回车直达）+ 分类筛选 + 随机看一个
- 📖 详情页：3D 查看器 + 介绍/原理/数据标签页
- 🖱️ 3D 场景支持拖拽旋转、滚轮缩放、自动旋转、重置视角
- 📐 每个场景附带「比例说明」，标明哪些是真实物理、哪些是压缩示意

## 🛠️ 技术栈

- Vite + TypeScript（零框架，轻量）
- Three.js + OrbitControls
- 程序化纹理：Value Noise / FBM、Canvas 2D、GLSL 着色器

## 🚀 快速开始

```bash
npm install       # 安装依赖
npm run dev       # 本地开发，默认 http://localhost:5173
npm run build     # 类型检查 + 生产构建（输出到 dist/）
npm run preview   # 预览生产构建
```

## 📂 目录结构

```
src/
├── main.ts            # 入口
├── style.css          # 全局样式
├── types.ts           # 类型定义
├── catalog.ts         # 天文现象数据（20 个条目：介绍/科学原理/数据）
├── textures.ts        # 程序化纹理生成器（星球/云层/环/光晕）
├── scenes.ts          # 12 类 3D 场景构建器
├── viewer.ts          # WebGL 渲染器 + 轨道控制封装
└── ui/
    ├── router.ts      # hash 路由
    ├── header.ts      # 全局顶栏
    ├── search.ts      # 搜索建议
    ├── home.ts        # 首页（星空英雄区 + 卡片）
    └── detail.ts      # 详情页（3D 查看器 + 标签页）
```
