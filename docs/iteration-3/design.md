## 1. P 阶段：加载性能（已落地）

1. **首屏关键样式内联 + 启动骨架**（`index.html`）
   浏览器在 JS/主样式表到达前即可绘制品牌与进度条；路由渲染推迟两帧，
   保证启动画面真的上屏一次。JS 完全失败时骨架仍给出可读提示。
2. **路由级按需加载**（`src/ui/router.ts`）
   首页静态引入（少一次请求且不含 three）；详情 / 目录 / 时间线动态 `import()`。
   详情路由额外并行预取 `viewer` + `scenes`，省掉串行往返。
   渲染带 token，快速切路由时丢弃过期渲染；模块加载失败有兜底页。
3. **详情页两段式**（`src/ui/detail.ts`）
   外壳、文字、数据表先同步渲染，三维引擎到达后再构建场景；加载态文案
   分「加载引擎 → 构建场景」两段。
4. **图表按需加载**（`src/ui/detail/panels.ts`）
   表格同步渲染（永远有内容），`metrics` + `viz` 两个 chunk 只在打开
   「数据」页时下载；切页签 / 离开页面会取消未完成的异步渲染。
5. **装饰层延迟**（`src/main.ts`）
   HUD 背景层在首屏两帧后、空闲期动态加载并淡入；标签页隐藏时自身暂停。
6. **构建分块**（`vite.config.ts`）
   `three` 独立 vendor chunk 长期缓存；其余按路由 / 功能自动分块。
7. **纹理生成提速**（`src/textures.ts`）
   - 颜色运算改为就地写入，去掉每像素的 `[r,g,b]` 数组分配（主因）；
   - 噪声改为「全局单表 + 种子偏移 / 轴交换」，不再按八度建表；
   - 概览场景（太阳系）用 256 宽纹理，单体展项保持 512。
8. **埋点**：`performance.measure('tianyi:engine-load' | 'tianyi:scene-build')`，
   性能脚本可直接读取，避免靠长任务反推。

## 2. R 阶段：真实感渲染（已落地）

实测：`tianyi:env-ibl` 约 39 ms（软件光栅化环境；真实 GPU 更快），
场景构建耗时未明显增加（地球 56 ms / 月球 67 ms / 太阳系 113 ms）。
像素级曝光测量（`px-check.mjs`，把画布读回 2D canvas 统计亮度）：
地球 0% 裁切、月球 0% 裁切、黑洞 0.93%、太阳 1.04%、星系 1.6%、蟹状星云 0.1%——
亮核占比都在 2% 以内，属于「中心亮」而非「大面积过曝」。

- **色调映射**：`ACESFilmicToneMapping` + 曝光控制，高光不再直接截断。
- **程序化 IBL**（`src/viewer/environment.ts`）：深空渐变 + 定向亮星经
  `PMREMGenerator` 预卷积，作为 `scene.environment`。金属与低粗糙度表面
  获得方向性环境反射；保持零外部资源依赖。
- **表面起伏**（`src/textures/relief.ts`）：与反照率同源的 fbm 高度场生成
  法线贴图（含环形山碗状剖面），岩石行星 / 卫星在斜射光下出现真实凹凸。
- **地球海面反光**：粗糙度贴图让海洋出现太阳镜面反射，陆地保持漫反射。
- **光照**：环境光大幅下调、平行光提亮，配合 IBL 得到清晰的昼夜分界线。
- **星空**：按色温分布恒星颜色、按星等分布亮度，并加入银河带。
