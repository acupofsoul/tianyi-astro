# 天文奇观观测平台 - 产品需求文档

## 1. 概念与愿景

**核心定位**：打造一个专业级天文观测控制台，融合工业设计的精密感与宇宙探索的神秘感。界面设计灵感来源于NASA深空网络控制中心、射电望远镜操控台以及科幻电影中的星际飞船仪表盘，创造一种"专业科学家操控宇宙仪器"的沉浸式体验。

**设计理念**：摒弃华丽的装饰性设计，采用"功能即美学"的工业设计哲学。每一个视觉元素都应该传达信息，每一个交互都应该有明确的目的。界面如同精密仪器的面板，让用户感受到操控宇宙的力量。

## 2. 设计语言

### 2.1 美学方向

**主题**：深空观测站控制台 (Deep Space Observatory Console)

- 参考：NASA任务控制中心、哈勃望远镜操控界面、科幻电影《星际穿越》飞船驾驶舱
- 风格：精密仪器感、极简功能主义、高科技控制面板

### 2.2 色彩系统

```
主色调：
- 深空黑：#0A0E14（背景基底）
- 观测灰：#1A1F2A（面板背景）
- 仪表银：#2D3548（边框/分割线）
- 指示蓝：#00B4D8（主要交互元素）
- 警告橙：#FF6B35（强调/警告）
- 数据绿：#00F5A0（成功/数值显示）
- 状态红：#FF3D3D（错误/重要提示）
- 星光白：#E8F1F8（文字/图表）

功能色：
- 引力波紫：#7B68EE（黑洞主题）
- 离子尾青：#00CED1（彗星主题）
- 双星金：#FFD93D（双星主题）
- 超新星橙：#FF8C42（超新星主题）
- 星云粉：#C77DFF（星云主题）
```

### 2.3 字体系统

```
主标题：JetBrains Mono（等宽精密感）
副标题：Space Grotesk（科技感）
正文：IBM Plex Sans（清晰易读）
数据：JetBrains Mono（数值对齐）
标签：IBM Plex Mono（仪表盘标签）
```

### 2.4 空间与布局

**整体结构**：
```
┌─────────────────────────────────────────────────────┐
│  HEADER: 站点标识 + 时间系统 + 状态指示器           │
├─────────────────────────────────────────────────────┤
│  ┌──────────┐  ┌────────────────────────────────┐  │
│  │          │  │                                │  │
│  │  导航    │  │                                │  │
│  │  面板    │  │      主观测区域                 │  │
│  │          │  │      (Canvas 模拟器)            │  │
│  │  快捷    │  │                                │  │
│  │  菜单    │  │                                │  │
│  │          │  │                                │  │
│  ├──────────┤  ├────────────────────────────────┤  │
│  │ 数据     │  │  控制面板                      │  │
│  │ 面板     │  │  (参数调节)                    │  │
│  └──────────┘  └────────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
```

**设计原则**：
- 黄金分割比例布局（导航30% + 主区域70%）
- 网格化设计：8px基础单位，16px标准间距
- 面板采用内嵌式设计，有明显的边界感
- 留白区域创造"观测窗"的视觉隐喻

### 2.5 动效哲学

**原则**：精确、可控、有意义

```
状态切换：200ms ease-out（快速响应）
面板展开：300ms cubic-bezier(0.4, 0, 0.2, 1)
数值变化：线性插值 60fps
数据更新：闪烁效果模拟LED显示
悬停反馈：边框发光 + 微缩放
加载状态：脉冲式进度指示
```

### 2.6 视觉资产

**图标风格**：
- 线性图标为主，1.5px线条粗细
- 几何化形状（圆形、矩形、三角形）
- 状态变化通过颜色/透明度表示

**装饰元素**：
- 网格线背景（模拟坐标纸）
- 角落装饰符号（模拟仪器面板）
- 刻度标记（模拟测量仪表）
- LED点阵效果（模拟数据显示屏）

## 4. 功能与交互

### 4.1 核心功能

1. **天文模拟器切换**
   - 点击导航项切换观测目标
   - 切换时画布区域有淡入淡出效果
   - 当前选中项有明显的视觉指示

2. **参数控制面板**
   - 滑块控制（拖拽反馈）
   - 数值输入框（支持键盘输入）
   - 预设快捷按钮
   - 参数变化实时反映到模拟器

3. **实时数据面板**
   - 显示模拟器相关天文数据
   - 数值动态变化（模拟实时监测）
   - 单位转换功能

4. **知识介绍面板**
   - 简短的科学解释
   - 关键术语高亮
   - 视觉图标辅助理解

### 4.2 交互细节

```
滑块交互：
- 拖拽时显示当前数值
- 释放时平滑过渡到最终值
- 边界值有弹性反馈

按钮交互：
- 按下时有下沉效果
- 释放后有脉冲动画
- 禁用状态显示锁定图标

画布交互：
- 悬停显示坐标信息
- 点击暂停/播放模拟
- 右键显示快捷菜单
```

## 5. 组件清单

### 5.1 导航组件

**TabNavItem**
- 默认：深色背景，灰色图标
- 悬停：边框发光，轻微放大
- 选中：蓝色边框，图标高亮，底部指示线
- 禁用：降低透明度，显示锁定图标

### 5.2 控制面板组件

**SliderControl**
- 标签 + 当前值显示
- 滑轨 + 滑块（可拖拽）
- 范围刻度标记
- 预设快捷按钮组

**DataDisplay**
- 标签 + 数值（等宽字体）
- 单位标识
- 变化趋势箭头
- 刷新动画

### 5.3 信息面板组件

**InfoCard**
- 图标 + 标题
- 描述文本
- 可折叠展开
- 链接到更多资源

### 5.4 画布容器

**ObservatoryCanvas**
- 深色背景 + 网格线
- 角落装饰元素
- 全屏切换按钮
- 截图功能按钮

## 6. 技术实现

### 6.1 技术栈

- React 18 + TypeScript
- Tailwind CSS（自定义配置）
- Canvas API（天文模拟器）
- CSS Modules（组件隔离）

### 6.2 性能优化

- Canvas 使用 requestAnimationFrame
- 状态更新使用 useMemo/useCallback
- 大量元素使用虚拟化
- 图片资源懒加载

### 6.3 可访问性

- 键盘导航支持
- ARIA 标签
- 对比度符合 WCAG AA 标准
- 减少动画偏好支持
